# Security

Context Delta is designed to be local-first and privacy-conscious.

## Reporting Security Issues

Please do not open public issues for sensitive vulnerabilities.

Use GitHub private vulnerability reporting if it is enabled for this
repository. If it is not enabled yet, contact the project maintainers through
a private channel before disclosing details publicly.

## Security Principles

- Raw source code stays local by default.
- Packet contents should be visible to the user.
- Secrets and environment files should be excluded or redacted by default.
- Metrics should avoid raw source code and prompt text by default.
- Policy exclusions should apply consistently across integrations.

## Sensitive Data

Do not include secrets, tokens, private keys, customer data, or proprietary
source code in issues, examples, logs, screenshots, or pull requests.
