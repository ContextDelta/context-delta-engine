# Positioning

Context Delta should be easy to understand before it is impressive to
engineers.

The public positioning:

```text
A local-first context layer for AI coding agents and spec-driven development.
```

The plain-language version:

```text
Context Delta shows your AI coding assistant what changed, what matters,
and why.
```

## What It Is

Context Delta is a context control layer.

It sits between the developer's existing workflow and the AI coding agent.
It prepares a focused context packet that can be shown to the user and sent
to tools such as GitHub Copilot, Claude Code, Cursor, VS Code, and
MCP-compatible agents.

## What It Is Not

Context Delta is not:

- a replacement IDE
- a replacement for GitHub Copilot, Claude Code, or Cursor
- a replacement for Spec Kit
- a generic chatbot
- a generic memory database
- a promise that smaller context is always better

It is a tool for making context selection explicit, fresh, and measurable.

## The Category

Avoid positioning this as "RAG for code." That phrase is too broad and does
not explain the product.

Better category language:

- context control for AI coding
- context packets for AI coding agents
- the context layer for spec-driven development
- local-first context assembly
- transparent AI coding context

## Messaging Pillars

### Less Stale Context

Specs, instructions, docs, and memories can drift. Context Delta helps mark
what changed and what may be stale.

### Fewer Missed Files

The engine looks for related tests, neighboring files, instructions, and
requirements instead of relying only on the active file or chat history.

### Visible Context

The packet viewer should make the product real. Users see what will be sent
and why.

### Keep Your Workflow

Context Delta should not force a new IDE or process. It should work with the
tools developers already use.

### Measurable Savings

Developers and managers should be able to see estimated token savings,
packet size trends, override rates, and stale spec warnings.

## Tagline Options

- Show your AI what changed.
- Less stale context. Fewer missed files.
- A context packet for every AI coding task.
- The missing context layer for spec-driven development.

Preferred tagline:

```text
Give your AI coding agent the right context, not the biggest context.
```

## Demo Story

The strongest demo is a before and after:

```text
Before:
28,000 tokens of mixed context
old specs, random open files, long chat history
related test missed

After:
7,800 tokens of focused context
changed file, affected test, relevant spec section, repo rule
72% estimated context saved
```

This is easier to understand than an architecture diagram and more memorable
than a feature list.
