GitHub Copilot

Use Copilot as usual. Send it better context.

Context Delta prepares a focused packet from changed files, specs, tests, and repo instructions before you ask Copilot to edit code.

Positioning

Copilot is the coding assistant. Context Delta is the local context preparation layer that makes the handoff visible.

Fit Adds Handoff Debug

No workflow reset.

Keep using Copilot Chat, agent mode, repo instructions, and prompt files. Context Delta gives you a reviewable packet first, so the prompt starts with less noise and fewer missing signals.

What Context Delta adds.

  • Changed-context detection from git or local snapshots.
  • Relevant spec and instruction sections with inclusion reasons.
  • Nearby tests and missing-test warnings.
  • Estimated token savings and budget pressure.
  • Excluded files and stale-context warnings.

Copilot-ready handoff.

Copy a Markdown handoff that states the task, packet readiness, included context, exclusions, risks, and recommended next steps.

npm run packet -- "Update admin refresh token behavior"
npm run handoff -- --format copilot

When Copilot misses, inspect the packet.

If the answer looks wrong, you can see whether the right spec, test, instruction, and changed file were present before retrying with a better packet.

Context Delta does not depend on hidden Copilot prompt internals. It prepares visible local context that developers can inspect and copy.
