VS Code

Keep context ready without living in a dashboard.

The extension brings quiet status, a remembered preferred agent, one-click handoffs, included files, warnings, replay prompts, approvals, diffs, and manager summaries into the editor.

Design goal

Make context review feel like a normal editor action, not a separate platform or a new workflow to memorize.

Dashboard Actions Review Team use

Activity bar dashboard.

The Context Delta view shows packet readiness, risk level, useful-context density, budget pressure, token savings, stale spec warnings, and included context groups. The status bar keeps the default view smaller: Context ready · risk.

Editor-native actions.

  • Prepare current changes for your preferred agent without retyping a task when the branch or diff is enough.
  • Switch the preferred agent between Codex, Claude, and Copilot once instead of choosing every prompt.
  • Check or fix VS Code setup from the editor when installation state is unclear.
  • Build or refresh a raw packet when you want the audit trail.
  • Open included files directly from the packet tree.
  • Copy Copilot or Spec Kit handoff text.
  • Copy a replay prompt or record an approve/needs-expansion decision.
  • Use collapsed advanced controls for exact include/exclude paths, stale-control cleanup, and general presets.
  • Open setup, drift, packet diff, insight, metrics, report, and summary webviews.

Review without friction.

The extension is intentionally thin over the local engine. Developers can trust that the CLI, MCP server, and VS Code surface are reading the same packet.

Useful for teams.

Teams can standardize context review while still letting developers use Codex, GitHub Copilot, Claude Code, or another agent.

The extension is marked preview until packaged extension-host testing and marketplace readiness are complete.
