Spec Kit

Make specs part of the agent's working set.

Context Delta complements Spec Kit and spec-driven development by keeping specs, plans, tasks, implementation files, tests, and rules visible in one packet.

Positioning

Spec Kit helps structure intent. Context Delta helps deliver the right slice of that intent to AI coding agents.

Fit Packet Handoff Scale

Built for spec-driven development.

Context Delta scans Markdown specs and instructions, finds relevant sections, and ranks them alongside changed implementation files and tests.

What the packet includes.

  • Changed code and nearby source files.
  • Relevant spec sections, plans, and tasks.
  • Acceptance criteria and repo instructions.
  • Related tests and missing-test warnings.
  • Exclusions, redactions, and budget pressure.

Spec Kit handoff.

The handoff format gives agents a concise task brief, included artifacts, constraints, and warnings so implementation stays grounded in the current spec.

npm run handoff -- --format spec-kit

Useful as specs grow.

As a repo gains more specs, Context Delta can keep agent prompts focused on the relevant slice instead of dumping every planning document into context.
