Context packets · Launch note

What is a context packet?

A context packet is the working set an AI coding agent should see before it changes code. It is smaller than the whole repo, more current than a long chat history, and more inspectable than hidden prompt assembly.

What belongs in the packet?

  • Changed files and affected neighbors.
  • Relevant spec sections, tasks, acceptance criteria, and repo instructions.
  • Nearby tests and missing-test warnings.
  • Excluded files with reasons.
  • Risk, budget pressure, redaction, and token-savings metadata.

Why it helps

When an agent makes a poor change, the question is often not whether the model is capable. It is whether the model saw the right files, current requirements, and relevant tests. A packet makes that visible.

Context Delta treats context as a reviewable artifact, not an invisible side effect of whatever files happened to be open.
