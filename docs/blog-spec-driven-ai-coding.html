Spec-driven · Launch note

Spec-driven AI coding needs context control.

Spec-driven development gives teams a better way to describe intent. The next problem is delivery: which part of the spec should the agent see for this task, and what code and tests prove it?

The spec is not the whole prompt.

Dumping every planning document into an agent prompt can be as harmful as sending no spec at all. Context Delta ranks relevant sections and attaches nearby code, tests, and repo instructions.

Where Spec Kit fits

Spec Kit structures intent. Context Delta prepares the current local packet that carries the right slice of that intent into Copilot, Claude Code, Cursor, or another MCP-compatible agent.

The goal is not to replace spec-driven development. The goal is to make it usable at agent speed.
