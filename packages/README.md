# Packages

Implementation packages will live here once the prototype begins.

Planned structure:

```text
packages/
  engine/            local indexing, diffing, ranking, packet building
  vscode-extension/  packet viewer and editor integration
  mcp-server/        MCP tools and resources
  shared/            packet schema, metrics schema, shared utilities
```

The first phase of the repo is documentation and product foundation. Code
should be added when the packet model and MVP scope are clear.
